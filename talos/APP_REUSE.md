## 实现与保留

- Intel 改为直接使用独立的通用搜索输入框；主站的地图搜索、结果导航和兼容接口保留。构建图确认 Intel 首屏不再包含 `useAdvancedSearch` / `search.shared`。
- Me 在 401 后导入完整 AuthGate。登录、资料设置、同步宿主、绑定等原有代码随原流程加载，未从个人资料面板删除能力。模块加载失败显示重试，重试刷新页面恢复资源加载。
- 复用点位 token 编码/域名、字体路径索引、i18n 纯工具及请求过期保护、实际主题订阅、框选显隐、导航/头像/Feed 展示样式；保留各应用词条和状态、字体资源入口及回退策略。

- Intel 进度持久化 P1 排除；同步协议、调度、冲突处理、完整标记数据、语言和头像数量保留。主站头像先打开面板的交互保留。托管和独立发布方案不变。

## 结论与更正

上一轮 APP_REUSE 报告的“就绪时间”取自 Playwright 等到元素后再读取时钟，包含轮询、通信及后续渲染任务的等待，不能可靠判断冷启动回归；Intel 仅等待搜索框还会早于档案内容就绪。本次撤回用旧表认定冷启动退步或提速的结论，旧 gzip/Brotli 体积统计仍有效。

本次改用浏览器内 MutationObserver 记录内容 DOM 出现时间，并记录内容可见后的两次 rAF 作为可见帧代理。Intel 必须出现档案卡片且两版本渲染量相同；最终每条 Intel 样本均为 535 张卡片。该代理不是 FCP、真实屏幕呈现时刻或 INP。

## 代码修复

- Intel 在 HTML 预载入口本来就会等待的三个字体：HMSans、Novecento Wide Medium/DemiBold。Vite 生成原有带 hash 的字体 URL，使用 crossorigin 保证与 CSS 字体请求模式匹配，缩短“JS 执行后才发现字体”的瀑布。
- Me 收到 overview 的 401 后即启动完整 AuthGate 下载，与 React 错误界面提交并行；渲染器共享在途 Promise，同页重挂可直接使用已加载的组件定义。没有缓存用户会话或组件实例，仍只在需要登录时获取模块；失败后的整页重试恢复保留。
- Me 的字体预载经 A/B 未见稳定收益，已撤回；原有翻译初始化、overview→contributions 请求顺序保留。本轮未改变同步协议、持久化 P1、数据、功能、词条和托管。

## 体积和保留的瓶颈

Intel 首屏 JS/CSS 与 d4e852d 字节相同，HTML 增加 406 字节。Me 首屏 JS 增加 88 字节（gzip 约 28 字节），CSS 不变；相对原始 52eedc5，两个 app 首屏 JS+CSS gzip 仍约减少 4.4% / 19.3%。新增字体预载没有新增字体文件或重复下载的需求。

Intel 的完整列表生成/测量及首帧后的初始化仍贡献约 80–108 ms 的前一秒阻塞，字体发现提前不等于这些工作消失。Me 仍受翻译初始化与 overview→contributions 串行影响。本轮未重写这些数据/布局流程，因此不把体积下降等同于冷启动等比例加速。

## 验证与复现

- 两个 app 生产构建、类型检查、受影响源文件及基准脚本 ESLint 通过；Me 6 个测试文件 / 29 项通过，含条件加载、在途请求复用及同页重挂缓存覆盖。
- Chrome 功能回归通过：搜索/清空恢复、拖动框选、主题、乱序语言切换、模块请求失败→重试、资料设置→内容刷新；桌面/移动计算样式对照无差异。
- 新增 scripts/bench-app-startup.mjs。只读取冻结产物，Playwright 可通过 PLAYWRIGHT_MODULE 指定现有安装，不增加项目依赖。脚本记录 DOM、帧代理、旧观察时间、字体/接口时序和前一秒阻塞；页面错误或两版本渲染工作量不同会失败。Intel 就绪条件为档案卡片，避免测到空壳。
- 运行方式（从 talos）：`PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs node scripts/bench-app-startup.mjs --baseline /path/to/frozen-baseline --candidate /path/to/frozen-candidate --out .cache/startup/results.json --rounds 10`。两目录各包含 intel/、me/。
- 本机 Apple M2 Pro、Node v25.9.0、Vite 6.2.1、Chrome 155 headless，DPR 1、reducedMotion=reduce，无网络/CPU 限速。fixture 路由禁用 HTTP cache，重复访问不代表线上 HTTP 热缓存；浏览器进程复用。未测线上网络、真实移动设备功耗或 INP。
